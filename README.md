# 🎮 Jogo do Número

Um jogo de terminal simples e divertido feito em Node.js onde o objetivo é adivinhar um número secreto entre 1 e 10.  
Você tem 3 tentativas para acertar e o jogo dá dicas se o número é maior ou menor que o escolhido.

## 🚀 Como jogar
1. Certifique-se de ter o Node.js instalado.
2. Clone ou baixe este repositório.
3. Instale as dependências:
   npm install
4. Execute o jogo:
   node index.js
5. Digite um número entre 1 e 10 quando solicitado.
6. O jogo informa se você acertou ou errou e mostra dicas até acabar suas chances.

## 📦 Dependências
- chalk → cores e estilos no terminal
- boxen → caixas decorativas
- figlet → título em ASCII art

## 🏆 Objetivo
Adivinhar o número secreto antes que suas chances acabem.  
Se acertar, recebe uma mensagem de parabéns 🎉.  
Se errar todas as tentativas, o jogo revela o número correto 💀.
